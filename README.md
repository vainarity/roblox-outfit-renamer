# roblox-outfit-renamer

bulk rename all your roblox outfits from the terminal.

## usage

1. install [node.js](https://nodejs.org)
2. clone the repo
3. run `node rename.mjs`
4. paste your `.ROBLOSECURITY` cookie token when prompted
5. type the name you want

## notes

outfits containing items you no longer own will be skipped automatically.
